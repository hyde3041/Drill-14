# Drill 14: 새의 비행 애니메이션

LEC16 실습의 잔디와 눈금 배경, 캐릭터 및 시간 표시 위에서 새 10마리가 좌우로 오가며 날개를 움직입니다. 방향키로 캐릭터를 움직이고 스페이스바로 공을 발사합니다. Esc 또는 창 닫기로 종료합니다.

## 실행

Python 3에서 이 폴더를 터미널로 열고 실행합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

테스트: `python -m unittest discover`

## 구현 원리

`bird_animation.png`는 5열 3행에 놓인 14장의 그림입니다. 마지막 칸은 비어 있으므로 재생에서 제외합니다. 경과 시간에 초당 14프레임을 곱해 애니메이션 위치를 갱신하고 14로 나눈 나머지로 반복합니다. 각 새의 시작 프레임을 다르게 주어 날갯짓이 동시에 겹치지 않습니다. 왼쪽으로 날 때는 이미지를 좌우 반전합니다.

각 새는 픽셀/초 단위 속도에 프레임 경과 시간을 곱해 이동합니다. 화면 양쪽 끝에서는 이동 거리를 왕복 경로에 투영해 방향을 바꾸며, 경계에서 남는 거리도 반영합니다. 따라서 프레임 속도가 달라져도 이동 속도가 일정하고, 한 프레임이 오래 걸려도 화면 안에 머뭅니다. 서로 다른 시작 위치와 속도를 가진 새를 정확히 10마리 생성합니다.

공은 캐릭터가 바라보는 방향으로 수평 속도 300픽셀/초, 위쪽 속도 300픽셀/초로 발사됩니다. 프레임 경과 시간과 중력 가속도 `9.8 * (10.0 / 0.3)`픽셀/초²를 적용해 포물선을 그립니다. 공 전체가 화면 좌우 밖으로 나가거나 공의 아랫부분이 지면 높이 40픽셀에 닿으면 제거합니다.

새 이미지는 제공된 LEC16 실습 자료를 사용했습니다. 구현에는 AI의 도움을 받았습니다.
